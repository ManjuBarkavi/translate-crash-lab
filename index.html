React · Google Translate · removeChild

Google Translate vs. React dropdowns

A settings form for a Spanish-language account, built in React 18.3.1 with a small design system whose menu triggers render their label through a component created in useCallback([children]). Translate it to English as a customer would with Google Translate, type in Nombre de la empresa or change a dropdown, and watch React throw NotFoundError: Failed to execute 'removeChild'. Then switch to the fixed code and try again.

Try it in three steps

  1. Leave mode 1 · As shipped and press Translate to English. Tu marca becomes Your brand, España becomes Spain, and each highlighted piece of text is now Google's <font> wrapper.
  2. Type one letter in Nombre de la empresa (now "Business name"). The phone dial code makes the whole form fail with "Your brand didn't load".
  3. Switch to 2 · With fix, translate again and repeat. Change Comunidad autónoma, País and the colour mode too. Nothing fails.

Use Chrome's real translator

Right-click the page and choose Translate to English (or use the translate icon in the address bar), then type in the business name field. If Chrome doesn't offer translation, use the simulator. It makes the same DOM changes and uses a fixed Spanish → English word list.

Use Scope to translate one field at a time. Industry stays in Spanish after translating because its value lives in an input, which Translate doesn't touch. That's also why it never crashes.

Why it fails

When a trigger's children change identity, its label component changes type, so React removes the old label's text nodes. Translate has already replaced those nodes with <font> elements, so removeChild throws. Wrapping the label in a memoised <span> means React only removes elements, which Translate never moves.

Mode 3 adds a global removeChild/insertBefore guard. Nothing crashes, but the dial code label piles up stale text, so it's a backstop rather than a fix.

Background: facebook/react#11538, "Make React resilient to DOM mutations from Google Translate". All components on this page are a minimal look-alike written for the demo. Sample data only.
